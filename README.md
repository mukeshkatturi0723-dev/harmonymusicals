# HarmonyMusicals

Refine the existing Harmony Musicals website so that it feels like it was designed and developed manually by a professional human designer/developer for a real local musical-instrument business.

IMPORTANT:
Do NOT redesign the website into another generic AI landing page.

The current website should feel intentional, authentic, practical and brand-specific.

HUMAN DESIGN DIRECTION:

Reduce unnecessary visual effects.

Remove generic AI-looking gradients.

Avoid excessive glassmorphism.

Avoid excessive rounded cards.

Avoid decorative blobs and abstract shapes unless they have a clear design purpose.

Do not put every section inside a card.

Use natural spacing and strong visual hierarchy.

Use photography as a major visual element.

Make sections feel connected rather than like separate template blocks.

Use asymmetrical layouts where appropriate.

Mix large visual sections with compact information sections.

Use subtle borders and shadows instead of excessive effects.

Keep animations restrained and purposeful.

Use consistent spacing throughout the website.

Make typography feel carefully selected rather than automatically generated.

Make buttons simple and practical.

Avoid excessive uppercase text.

Avoid unnecessary icons.

BRAND PERSONALITY:

Harmony Musicals should feel:

Established

Trustworthy

Musical

Local

Professional

Experienced

Passionate

Approachable

It should feel like a real Visakhapatnam music store that has upgraded its digital presence.

HOMEPAGE:

Do not create 15+ sections.

Use a strong, focused structure:

Navigation

Hero

Shop by Category

Featured Instruments

Music School

Services

Store Experience

About / Heritage

Customer Reviews

Contact / Footer

HERO:

Make the hero feel photographic and editorial.

Use one strong instrument/store image rather than multiple floating images.

Headline:
"Find Your Sound."

Supporting text should be short and natural.

Use two simple CTAs:
"Explore Instruments"
"Visit Our Store"

Do not use exaggerated marketing language.

PRODUCTS:

Make product cards practical.

Each card should prioritize:

Product image
Brand
Product name
Price
Availability
View Product

Avoid putting unnecessary badges, stars, tags and decorative elements on every card.

Use realistic demo content but clearly separate it from verified client information.

CATEGORY SECTION:

Use large photography.

Do not use six identical rounded cards.

Create visual variety:

Large featured category

Smaller supporting categories

Different image crops

Consistent typography

MUSIC SCHOOL:

Make this feel like a real service offered by a music store.

Use:

Strong photography

Short explanation

Course list

Simple CTA

Avoid fake statistics or exaggerated claims.

SERVICES:

Combine:
Repair
Rental

Use a clean two-column layout rather than two generic cards.

STORE EXPERIENCE:

Make the physical Visakhapatnam store important.

Use:

Store photography placeholder

Location

Contact

Opening hours placeholder

Google Maps area

This should communicate that Harmony Musicals is a real physical business, not an imaginary online startup.

COLOR:

Use a restrained palette:

Near black
Warm ivory
Muted gray
Champagne/golden accent

Do not make gold appear everywhere.

Use the accent only for:

Primary buttons

Small highlights

Important links

Selected states

TYPOGRAPHY:

Use one primary modern font and optionally one display font.

Do not use more than two font families.

Create clear hierarchy:

Large hero heading
Medium section heading
Small supporting text

Do not make every heading enormous.

IMAGES:

Prioritize realistic musical-instrument photography.

Avoid obvious AI-generated images.

If actual Harmony Musicals photographs are not available, use clearly replaceable image placeholders and structure the layout so the client's real photographs can later be inserted.

ANIMATION:

Use only subtle interactions:

Fade/slide section entrance

Image hover zoom

Button hover

Product card hover

Smooth navigation

No constant floating animations.

MOBILE:

The mobile version must feel deliberately designed, not simply compressed desktop content.

Pay special attention to:

Navigation

Product cards

Category browsing

Buttons

Image proportions

Text spacing

Forms

FINAL TEST:

Review every section and remove anything that looks like it was added only because an AI website builder commonly adds it.

The final result should look like:
"A developer spent several days designing this specific website for Harmony Musicals."

It should NOT look like:
"An AI generated a generic music-store template."

Do not add new business claims while making these visual changes.
